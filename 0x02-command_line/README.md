# 0×02. CommandL line Fundamentals & Shell Scripting

## purpose
this assignmenent introduces essential linux command-line operations and bash scripting.it builds the skills needed to work efficiently in a  terminals:
navigating the filesystem with absolute and relative paths, inspecting,creating,coping,moving,renaming and removing files and directories understanding
basic file permissions and command output redirection, and locating files and searching their contents with `find` and `grep`.
 it ends with a bash script(using variables, arguments and conditionals) that automate the creation of a  reusable website project structure. 

## Learning goals
- Navigate the Linux filesystem using absolute and relative paths
- Inspect files and directories using terminal commands
- Create, copy, move, rename and remove files and directories
- Understand basic file permissions and command output redirection
- Locate files and search their contents using `find` and `grep`
- Understand basic Bash scripting: variables, arguments and conditionals
- Write and run a Bash script that generates a website project structure
- Document practical work and keep an organized GitHub repository

## Structure
- `task-1/` – Linux terminal navigation and environment exploration
- `task-2/` – File and directory management, output redirection and permissions
- `task-3/` – Finding files with `find` and searching contents with `grep`
- `task-4/` – Bash script: automated website project generator
